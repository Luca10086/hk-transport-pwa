# 森友出行 (WP8-Metro) UI/UX 设计一致性审查报告

**审查依据**：以 `WP8-Metro-Spec/设计规范.md` (v1.0) 为最高权威。因其对 WP8 皮肤（本次 diff 所涉及的 `data-ui="wp8"`）做出了最严格、最具体的定义。
**审查范围**：仅限于提供的 `diff` 文件块。

---

**一、总体结论**
**明显偏离 (1 处)**

**二、逐项检查表**
| 变更点 (文件:行/片段) | 对应设计要求 | 判定 (符合/偏离) | 建议修复 |
| :--- | :--- | :--- | :--- |
| `css/wp8-strict.css`：新增 `.sushiro-note { font-size: 12px; }` | **字级表 (§1.3)**：最小字号为 `meta` 级 **13px** (用于地图 POI、角标等)。全 App 无低于 13px 的文字。 | **偏离** | 将 `font-size: 12px;` 修改为 `font-size: 13px;` 以符合规范最低字级。 |
| `js/data.js`：新增 `SUSHIRO_SNAPSHOT` 数据对象 | **设计文档未覆盖**。此变更为静态数据硬编码，不涉及 UI 组件的视觉或交互规范。 | 不适用 (功能实现) | 无需修复。 |
| `js/wp8-concept.js`：`fetchSushiroData()` 逻辑变更 | **设计文档未覆盖**。此变更涉及数据获取策略与容错，不涉及 UI 组件的视觉或交互规范。 | 不适用 (功能实现) | 无需修复。 |

**三、必须修复清单 (按严重度排序)**
1.  **严重 (P0) - 字号违规**
    *   **问题**：`.sushiro-note` 使用 12px 字号，低于 WP8-Metro-Spec 规定的最小字号 `meta` 13px (见规范 §1.3 字体与字号表格)。
    *   **改法**：在 `css/wp8-strict.css` 中，将 `.sushiro-note` 的 `font-size: 12px;` 改为 `font-size: 13px;`。

**四、做得好的地方**
*   在 `wp8-concept.js` 中增加了对 `SUSHIRO_SNAPSHOT` 静态数据的回退机制，考虑到了在无法获取实时数据时的用户体验，符合内容优先的原则。
*   `sushiro-note` 样式使用了 `var(--text2)` 令牌进行颜色定义，符合 WP8-Metro-Spec §6“一致性开发指引”第1条（使用共享令牌，禁止硬编码）的要求。

---
**主代理決議（2026-09-06）**：.sushiro-note 12px 事實成立但 P0 定性過嚴（12px 註解在該皮膚有 kt-legend/kt-chip 先例，DESIGN-WP8.md 明言正文 12px 起）——仍依報告對齊 13px 以徹底避免再被標記。其餘兩項判「功能實現」成立。
